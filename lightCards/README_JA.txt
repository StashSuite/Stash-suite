Light Scene Cards v1.6.1（軽いシーンカード）

Valkyr Scene Cards の代わりのシーンカードです。

■ v1.6.1 の変更
- 表紙だけ：浮かぶプレビューを、カードに重ならない所（上 → 下 → 右 → 左の入る所）に出す。
  カードの上に出るタイトル・出演者を隠さない。どこにも入らない時だけカードに重ねる。

■ v1.6.0 の変更
- 横型のタグ：空いた高さに丸ごと入る行数だけ表示（行の途中で切れない）。入らないタグは下の段のタグ数ボタンから。
  入る行数は見えているカード1枚で測り、ページ全体に設定（500枚を測らない）。
- 女優とタグをひと目で見分けられるように：女優＝丸い枠の太字、タグ＝小さな四角・頭に「#」・薄い色。

■ v1.5.0 の変更
- 横型の1行目：大事な順（スタジオ ＞ 発売日 ＞ 容量・画質）に並べ、入らない物は丸ごと隠す（…で切らない）。
  スタジオは明るい太字、発売日は普通の文字、容量・画質は小さな枠付きで、何の情報か見分けやすく。
- カードのタグ（横型の空き・タグ一覧）は、ミニプレイヤーのタグと同じ：好き嫌いの色だけ付き、クリックで好き嫌いのポップアップ
  （もう一度で閉じる。Ctrl+クリックでタグページ）。Tag Weighted Recommendations の「− 数値 ＋」ボタンは付けない。
- プレビュー中は、表紙の上の「あとで見る」と選択のチェックを隠す。

■ v1.4.0 の変更
- 横型の情報の欄の空きを減らした：スタジオと発売日・容量・画質を1行に。空いた所にタグの名前を並べる（クリックでタグのページ）。
  設定「タグの名前（横型の空いた所に）」で消せる。
- プレビューは、どの形でも「表紙にマウスを乗せると始まり、表紙から離れると止まる」に統一（横型でカードの情報の上でも続いていたのを直した）。
  場面送りの位置も表紙の上での左右の位置。
- 表紙だけ：プレビューはカードの上に浮かぶ16:9の窓（幅は表紙の約2.2倍、最大560px）。スクロールで閉じる。
- プレビュー動画も場面画像も無い作品は、プレビューの枠を出さない。
- ミニプレイヤーの「あとで見る」ボタンを表紙の中（右上）に（ミニプレイヤー側で、表紙を置き場にするよう変更）。

■ v1.3.0 の変更
- カードの大きさを、一覧の上の自分のスライダーで決めるようにした（形ごとに覚え、サーバーに保存。ページを移っても戻らない）。
  Stash 本体の拡大スライダーはページを移ると戻るので、このカードを使っている間は隠す。
  目安の幅に一番近い列数で行いっぱいに並べる（初期値：縦型300px・横型340px・表紙だけ190px）。
- 横型を狭い幅向けに：高さ＝幅÷1.75、表紙の表側は高さいっぱいの縦長。幅340pxで表紙約130px・情報約190px（2000px幅の画面で6列）。

■ v1.2.0 の変更
- 3つ目の形「表紙だけ」：パッケージの表側を縦長に並べ（縦型 n 列の幅なら n×1.6 列）、タイトルと出演者はマウスを乗せた時に下から重ねて表示。品番は重ねた後もコピーできる。
- 形の切り替えを3つのボタン（縦型／横型／表紙だけ）に。今の形のボタンに色が付く。
- プレビューの方式を選べる：動画／マウスの左右で場面送り（シークバー用の画像で、作品全体をすばやく見渡せる）。動画が無い作品は自動で場面送り。
- 一覧の上の Stash 本体のアイコンボタン（保存した絞り込み・並びの向き・その他の操作・表示の種類）に、マウスを乗せた時の日本語の説明を付けた。

■ v1.1.0 の変更
- 横型の空きを減らした：縦型 n 列の幅なら n×3/4 列（5列→4列）。表紙の表側を幅30%に、高さは全カード同じ（幅÷2.2）、タイトルは1行多く。
- 横型のプレビュー動画は、表紙の欄ではなくカード全体に重ねて映像全体を表示（カードから離れると止まる）。
- 品番をクリックでコピー（「コピーしました」と表示。ページやミニプレイヤーは開かない）。

■ 軽さ
- Stash が一覧の取得で渡す内容だけで描くので、カードごとの問い合わせがありません（Valkyr は 500件の一覧で数百回）。
- 画面の外のカードは描きません（content-visibility）。部品の数も Valkyr の約半分です。
- プレビュー動画は、表紙にマウスを乗せた時だけ作ります。

■ 使い方（すべてマウスで）
- 一覧の上の [縦型／横型] ボタン：縦型（表紙が上）と横型（表紙が左・情報が右）を切り替え。
  横型は、縦型が n 列の幅なら n×3/4 列で並びます。トップページの横スクロールは常に縦型です。
- ⚙ ボタン：表示設定。
  - 横型の表紙：パッケージの表側だけ／全体。パッケージ画像（横長 約1.5:1）でない画像は、常に全体で表示。
  - タイトルの行数（1〜3行）、プレビュー動画の有無。
  - 表示する項目：品番・長さ・スタジオ・発売日・容量・画質・出演者（男性も出すか）・評価・再生回数・O回数・タグ数・別ファイル数・整理済み・続きの位置。
  - 「Valkyr のカードに戻す」：Valkyr Scene Cards を有効にして読み込み直します。戻した後は、一覧の上の「軽いカードに切り替え」でこちらに戻れます。
- 評価（★）：ミニプレイヤーが入っていれば、クリックで評価。
- タグ数：クリックでタグの一覧（もう一度・外を押す・スクロールで閉じる）。
- 出演者：入らない人は Card Rarity の「+N」にまとまります。

■ 仕組みの注意
- Valkyr と両方を有効にすると、Valkyr が外側で問い合わせを続けて軽くなりません。切り替えボタンは片方だけを有効にします。
- 設定は Server Store で Stash サーバーに保存（キー lightCards.v1）。
- ファイル：settings.js（設定）、card.js（カード）、toolbar.js（ボタン・設定パネル・タグ一覧・切り替え）、lightCards.css。

■ v1.7.0（2026-11-01）
- スタジオ・出演者・タグのどれも無い作品のカードに「まだ情報がありません ／ 品番で探す」を出す。押すとミニプレイヤーのスクレイプ画面を、ファイル名から推測した品番を入れて開く。
- 一覧の上の Light Cards のボタン（縦型・横型など）の高さを、ほかのボタン（34px）にそろえた。
- （1.7.1）「探す」は Google 検索（新しいタブ）に変更。検索語は品番 → 題名・ファイル名の「ABC-123」の形 → ファイル名から推測した品番 → ファイル名の順。表示は「情報なし」に短く。
- （1.7.1）表紙だけ：動画の場面（16:9）は真ん中で切る（右で切ると端だけが残っていた）。パッケージ画像だけ右側の表を見せる。
- （1.7.1）縦型：長い品番は半分までで … に。タグの段の右端をぼかして続きがあると分かるように。マウスを乗せたカードは少し浮く。
- （1.7.1）出演者のリンクに data-performer-id を付けた（Card Rarity が表示中の出演者を「+1」に数えていたのを直すため）。

■ v1.8.0（2026-11-01 Liquid Glass）
- カードをガラスに：表紙を大きくぼかした色がカードの地に透ける（.lc-ambient を置く。見た目は Suite Core の glass.css）。
- 表紙の上の札・出演者・タグも薄いガラス。表紙だけの形の、乗せた時の情報欄も表紙の下に浮くガラスに。

■ v1.9.0（2026-11-01）
- 表紙の上を整理：長さとおすすめ順の順位は出さない。左上＝選択（丸いガラスのチェック）、右上＝スクレイプ・あとで見る（34px に拡大）、左下＝枚組・プレビュー中の時刻。
- 評価の星を光るガラスの星に（金色のグラデーション＋にじむ光、未評価は半透明の白）。
- 縦型：再生回数・O回数・別ファイル数を日付などの行に入れ、下の段をやめた（付いたカードだけ縦に伸び、行ごと間延びしていた）。
- 左のサイドパネル（絞り込み）・表示件数の選択肢もガラスに（選択肢が白地に白文字で読めなかった）。見た目は Suite Core の glass.css。
- （1.9.0 追記）評価の星に乗せると枠が二重に見えていたのを直した。左のサイドパネルをより透けるガラスにし、ページの地にうっすら色を置いた（Suite Core の glass.css）。
- （1.9.0 追記2）長さは表紙の右下に戻した。プレビュー中（特に「元の動画で場面送り」）はその位置に再生位置の時刻を出す（左下の評価の星と重なって二重の枠に見えていた）。
- 右上のスクレイプ・あとで見るを同じ 34px の丸いガラスにそろえた（共通の見た目の決まりに上書きされて大きさ・角が違っていた）。プレビュー中も左上の選択・右上のボタンを出したまま押せるように。
- サイドパネルを開いている時、一番左のカードがパネルの下に入っていたのを直した。
- （1.9.1）O回数をしずくのアイコンに（「O 3」の文字をやめた）。カードのスキン（glass/clear/frost/vivid/solid）と「使う／使わない」は Suite Core の設定の「見た目」から。
