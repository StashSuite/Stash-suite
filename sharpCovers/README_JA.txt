Sharp Covers v1.1.0

シーンカードのカバー画像を、表示サイズちょうどに高品質に縮小し直して差し替えます。
大きなカバー（例 2184×1468）をカード（例 274×154）へブラウザ任せで縮めた時のギザギザ（ジャギー）を減らします。

・画面に入ったカードだけ処理（同時に2枚ずつ）。カードの大きさが15%以上変わったら作り直し。
・元画像が必要サイズの1.4倍以下なら何もしない（縮小がゆるく、ギザギザが出にくいため）。
・元の画像ファイルは変更しません。作った画像はこのタブのメモリにだけ置きます（ディスクは使いません）。
・Stash のセキュリティ設定（CSP）で blob: の画像が使えないため、data: 形式で差し替えています。
・元のURLは data-src に残すので、ミニプレイヤーのカードクリックはそのまま動きます。

■ v1.2.0（スクロールが引っかからないように）
- 画像の読み込み・縮小・シャープ・JPEG 変換を Web Worker（lib/resizeWorker.js）に移しました。
  以前は一覧のスクロール中に最大約1秒固まることがありました（500件・初回表示で測定、1.0秒 → 0.09秒）。
- Stash のセキュリティ設定（worker-src blob:）に合わせ、スクリプトを読んで blob: URL から Worker を作ります。

■ v1.1.0
・縮小後に軽いシャープ（強さは sharpCovers.js 冒頭の SHARPEN）。
・作った縮小画像をブラウザ（IndexedDB）に最大800枚（約25MB）保存し、次からは描画前に差し替え（時間差の切り替わりを見せない）。
・消す時はブラウザのコンソールで StashSharpCovers.clear()。
