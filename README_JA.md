# Stash Suite (Free版)

[English](./README.md) | **日本語** | [繁體中文](./README_ZH_TW.md) | [简体中文](./README_ZH_CN.md) | [한국어](./README_KO.md)

[StashApp](https://stashapp.cc/) の一覧表示・再生・整理・閲覧体験を快適にする統合プラグイン集です。**AV（JAV）・ローカル動画・漫画／同人誌コレクション**の大量管理に最適化しています。  
外部の Python パッケージ（`pip`）や追加サーバーは不要で、フォルダをコピーするだけで使えます。

- **5言語対応**：日本語 / English / 繁體中文 / 简体中文 / 한국어（自動判定＆設定画面から切替可能）
- **マルチOS対応**：Windows / macOS / Linux / Docker

---

## Free版 収録プラグイン（11 個）

- **Suite Core**：共通基盤・10種の背景テーマ・タブ式統合設定画面・外部プレイヤー直接起動
- **Server Store**：全プラグインの設定を Stash サーバーへ自動同期
- **Quick Genres**：ワンクリック並び替え・未視聴/★4+/新着スイッチ・お気に入りボード・顔の帯・強化版出演者パネル（写真あり優先・別名検索・その場★評価・ランダム選出）
- **Light Scene Cards**：超軽量シーンカード（縦型／横型／表紙だけ・16項目の表示カスタム・プレビュー）
- **Scene Card Rarity**：評価に応じたカード演出（6テーマ）＆クリック式出演者カード
- **Grid Player**：カードを `Shift＋クリック` で最大9画面まで同時再生
- **Click Popovers**：カードのタグ・出演者ポップアップをクリック開閉に変更
- **Search History**：検索窓に最近の検索履歴を表示
- **Auto Backup**：7日ごとに Stash DB を自動で安全バックアップ
- **Sharp Covers**：Web Worker によるカバー画像の高品質シャープ縮小
- **View Mode**：カテゴリモード切替（初期オフ。設定画面からオンにできます）

## インストール方法（3ステップ）

1. このリポジトリの **Code → Download ZIP**（または Releases の最新 ZIP）をダウンロードして解凍します。
2. 中にある**各プラグインのフォルダ**（`suiteCore`, `serverStore`, `lightCards` など）を、Stash の `plugins` フォルダへコピーします。
   - **Windows 標準の例**：`C:\Users\<ユーザー名>\.stash\plugins\`
   - **macOS / Linux 標準の例**：`~/.stash/plugins/`
   - **Docker の例**：`/root/.stash/plugins` にマウントしているホスト側フォルダ
   - ※ `plugins` フォルダの場所は、Stash の **設定 → システム** または `config.yml` で確認できます。
3. Stash を開き、**設定 → プラグイン →「プラグインを再読み込み」** を押してから、ページを再読み込み（`F5`）します。

---

## 導入後まずやること

1. 画面右上のメニューに新しく出た **「設定」ボタン（歯車）** を開きます。
   - 表示言語・背景テーマ（10種）・カードの縦型／横型・表示項目（16項目）をリアルタイムで変更できます。
2. **複数同時再生（Grid Player）**：シーンカードを `Shift＋クリック` すると再生ウィンドウが最大9個まで並びます。

## よくある質問・ライセンス

- **設定はどこに保存されますか？**  
  `Server Store` により Stash サーバー側へ自動保存されるため、別のブラウザや別PCから開いても同じ設定が引き継がれます。
- **不要なプラグインだけ止めたい**  
  Stash の **設定 → プラグイン** から個別にオン／オフできます（`Suite Core` と `Server Store` は共通の土台なのでオンのままにしてください）。
